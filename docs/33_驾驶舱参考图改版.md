# 管理端驾驶舱参考图改版（2026-09-18）

## 范围与实施计划

按老板本轮提供的驾驶舱参考图调整现有老板首页：六张 KPI → 趋势与团队 → 客户贡献与关注 → 项目管道与本人待办。仅修改前端页面、驾驶舱限定样式、共享令牌补充和测试；不改后端接口、业务公式、权限、路由、数据库。销售员页面不改。

- 驾驶舱限定侧栏 178px、顶部栏 48px；浅灰蓝背景，白卡，品牌蓝图表与交互。
- 桌面 6 列 KPI，1250px 以下 3 列，手机 2 列；内容区域窄屏单列。
- 销售金额柱与成交客户折线双轴并列；支持聚焦成交客户、展开每月精确数值。
- 团队默认 Top 5，保留展开全部；贡献客户可直达客户详情。
- 预警默认前四项，剩余摘要和所有客户关注入口保留。
- 原完整财务指标、数据警告、更新时间、指标字典代码保留在页尾可展开的数据说明。

## 数据映射与参考图差异

| 区域 | 实际来源及约束 |
|---|---|
| 月份 | overview 当前月；只读展示，提示历史月份从销售分析查看，不做无效月份选择器 |
| 销售额 / 成交客户 | overview 原有指标，保留待核实状态与源销售核对名称 |
| 环比 / 同比 | overview SALE_MOM / sales SALE_YOY；无基期显示 —，不编百分比 |
| 目标达成率 | 沿用已有“已设置个人目标的人员合计”口径，未核实不展示比例；金额合计以整数分计算 |
| 销售毛利 | product-margins SALE_GROSS_PROFIT；明确最近一次采购价口径及成本覆盖，非财务毛利 |
| 应收 | overview EXEC_AR_BAL 财务报表月末余额；缺报表显示 — |
| 首次成交客户 | sales CUS_NEW_TRANSACT；不用新增建档客户命名；完整历史不足显示理由 |
| 客户贡献 | overview 已排序 Top 5；按销售额，不实现语义不明确的“按成交客户数”开关 |
| 预警 | 复用目标缺口、客户沉睡/疑似流失、项目停滞、逾期任务；不伪造参考图的大额应收/发票异常数 |
| 项目 | 当前开放项目、本月预计成交、加权金额、停滞项目；非历史总项目/赢单/输单；详细金额与阶段在折叠区 |
| 我的待办 | CRM tasks 按当前 userId 过滤今日/本周/逾期，opportunities 按本人+open 过滤；不调用仅支持销售/经理的 BI workbench |
| 本人列表计数 | 现有列表单页上限 100；满页明确显示 100+（至少100），不将分页条数伪装完整总数 |

本人工作与项目管道为跨数据源 CRM 范围；销售/财务按所选来源。用户切换来源后清空旧补充指标，各补充请求独立重试，不因某卡请求失败遮蔽已加载的主页面。
