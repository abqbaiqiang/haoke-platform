# 数据驾驶舱改版与问题修复 — 2026-09-14

用户已确认数据驾驶舱预览布局并授权实施。本次在现有客户分析改动上完成界面调整及审查问题修复，历史问题依据见 `19_总体检查与UI改版建议.md`。

## 实施范围

- 首页采用深色分组侧栏、浅色内容区、四项经营摘要；销售趋势与团队目标并列，客户贡献与关注事项并列，财务区域按可用数据集中展示。
- 趋势可切换销售额/成交客户；本月显示截至日期及未完月标识，保留精确数值和指标口径。目标未设置或销售口径未核实时，完成率保持不可用。
- 客户贡献与关注事项可打开客户详情；客户分析、团队执行、待办及设置提供直接入口。同事无地址参数登录默认进入个人工作台。
- 顶层导航、分析标签和客户详情写入页面地址，支持刷新恢复页面及浏览器返回。月份、数据源和临时筛选仍为页面内状态，刷新会使用默认值。
- 客户列表改为紧凑表格，显示名称、编码、负责人、等级和操作；详情新增分区快捷跳转。未扩展最近跟进/下次安排聚合字段，也未新增编辑抽屉。
- 分析筛选栏放在正文上方；手机图表单列，宽表在自身容器滚动；正文标签与侧栏各自使用独立样式。
- 老板可通过页面维护 BI 参数、RFM 阈值和 CRM 设置，与现有后端授权一致。

## 已修复问题

| 问题 | 修复与验证 |
|---|---|
| 正常绑定后的潜客转化漏计 | 保留被停用的潜客绑定别名，按当前正式客户归属授权；完整历史核实后，以有效普通销售的首次日期计算；覆盖真实绑定接口、转交后越权、退货/作废/未来订单排除 |
| 退货未从客户分析金额扣除 | 使用既有 `order_value` 扣减已确认退货；订单数和最近成交只使用普通销售。固定样本销售 1000.30、退货 50.00、4 单，结果 950.30、客单价 237.58 |
| RFM 高频阈值改变复购公式 | 周期复购继续固定为同周期至少 2 单，RFM 阈值只影响分层；本月指标与历史画像分别展示 |

| 老板设置入口缺失 | 开放已有权限允许的入口和 RFM 参数表单，真实浏览器提交并刷新验证 |
| 手机分析页撑宽、正文标签难辨认 | 去除内联固定双列，正文移出工具栏，收窄侧栏 CSS 选择器；1440/768/390 px 检查 |
| Ruff 与旧 UI 用例失败 | 修复 E731；客户列表和导航定位跟随新页面结构；新增驾驶舱真实导入/下钻/设置浏览器回归 |

## 数据及交付边界

本次不更改数据库结构，无新增 migration；不修改真实交易事实、销售核实结论、负责人映射或公司目标。浏览器写操作使用随机 schema 的独立测试数据库和人工样本。本地开发服务恢复使用既有数据库。

当前真实源销售口径、历史覆盖、人员映射仍待业务确认；财务缺失期间保留明确提示。界面不会用示意数字或假零值填充这些缺口。

Docker/NAS、生产规模性能及人工业务验收仍待补；本机原生测试通过不代表已完成生产部署验收。
