# 松茂经营管理平台 V1 待确认参数与后续输入

**状态：** 非阻塞项。除非明确标注“阻塞”，Codex 应将其做成后台配置、隐藏未启用模块或使用合理默认值，不得擅自创造业务事实。

## 1. CRM 参数

- A/B/C 等级客户的跟进超期阈值；
- 客户进入公海的条件和是否允许自动回收；
- 公海客户领取后多久无跟进可再次回收；
- 普通销售修改已提交跟进记录的时间窗口；
- 是否允许销售自行创建标签，还是仅能选管理员标签；
- 沉睡 90 天、疑似流失 180 天目前为初始建议，后台可改。

## 2. 销售目标

V1 必须：销售额月目标。  
可选但数据条件满足后再启用：毛利目标、新成交客户目标、回款目标。

不得因为这些可选目标尚未确定而阻塞 M0-M2。

## 3. 敏感数据

默认：

- 普通销售不看成本、毛利、公司财务；
- 销售经理默认不看成本/毛利，可由老板后续开启；
- 财务对 CRM 客户过程信息按授权查看。

## 4. 还需从精斗云补充/重新导出的样本

为 M4 和更准确的数据体检准备：

- 商品档案（优先 xlsx/csv）；
- 客户档案 xlsx/csv；
- 供应商档案 xlsx/csv；
- 采购单 xlsx/csv；
- 库存明细/库存余额或库存快照；
- 收款单/应收明细；
- 付款单/应付明细；
- 销售退货；
- 采购退货；
- 如能获取：实际销售出库成本/成本明细。

老 `.xls` 可以兼容，但不应为了兼容古董格式牺牲整个导入架构。

## 5. 精斗云 API

真实对接时需要：

- 届时官方 API 文档；
- 应用认证方式；
- AppKey/AppSecret 等；
- 企业/账套标识；
- 接口权限范围。

M0-M4 不依赖 API。

## 6. AI

V1 核心上线不依赖 AI。启用 AI 时再确定 Provider、模型、费用和数据脱敏策略。

## 7. 阻塞原则

以下才算真正阻塞开发：

- 指标公式存在两个互斥且无法配置的口径；
- 无法确定某数据表的来源主键，可能造成重复事实；
- 权限要求存在明显互斥；
- 数据迁移存在丢失正式数据风险。

其余偏好型问题应做成配置项或延后，不要停止整个项目等老板决定按钮圆角几像素。
