### 本轮失败与修复

1. PostgreSQL Windows 初始化受限令牌/中文路径错误：使用本项目独立 ASCII 临时目录启动便携 PostgreSQL；仅监听 loopback，不注册系统服务。
2. E2E 错误提示定位器同时命中 Next.js 隐藏播报节点：限定为包含实际错误文案的 alert，完整 12 项重跑通过。
3. Alembic 路径分隔弃用提示：加入 path_separator=os。
4. 部署复核发现非 root 后台写入宿主挂载目录需要权限准备：增加一次性 storage-init 服务，仅初始化 uploads/backups 的约定目录，不改数据库目录。
5. Windows 受限会话 pg_ctl status 无法可靠检查管理员启动的数据库：本地启动器先检测 loopback 端口，再用真实凭据验证数据库连接，防止误判后重复启动；再次执行已通过。

## 如何本地启动

当前机器已安装本项目依赖，并已初始化 .env 和演示账号。在项目根目录：

```powershell
.\scripts\start_local.ps1 -SeedDemo
```

访问 http://localhost:3000。管理员用户名见 .env 的 INITIAL_ADMIN_USERNAME，密码见 INITIAL_ADMIN_PASSWORD。演示账号 demo_owner/demo_manager/demo_sales/demo_finance/demo_admin 使用 .env 的 DEMO_PASSWORD。

重新运行本地测试：

```powershell
.\.venv\Scripts\python.exe scripts/run_tests.py
$env:E2E_BROWSER_CHANNEL = 'msedge'
.\.venv\Scripts\python.exe scripts/run_e2e.py
```

第二条测试命令要求应用已运行、演示账号已初始化。完整新机、NAS、HTTPS、备份步骤见根 README。
