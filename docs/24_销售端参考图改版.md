# 销售端参考图改版

## 范围与依据

用户在 2026-09-14 提供四张工作台、待办、客户、我的业绩参考图，并授权按图片与前次信息架构复盘一并修改。参考图是视觉方向，不作为数据、字段或权限事实。方案先前已确认，不再次进行视觉方向投票。

实施顺序：核对角色与接口 → 销售独立四页 → 任务/客户行动摘要 → 跟进闭环 → 权限及浏览器验证 → 文档与验收。使用 Impeccable 的 Operate 原则和实现质量检查；用户指定的参考图优先于旧视觉指令。

## 页面与交互

- 销售主导航仅工作台、客户、待办、我的业绩。默认工作台；头像菜单退出。原老板/管理角色页面维持现有入口。
- 工作台左侧今日工作与最近跟进，右侧紧凑业绩与逾期待办提醒。每个计数来自完整范围查询，首页显示前 6 项并明确总数。
- 今天统计上海时区当日未完成任务；逾期为截止时间早于当前时间。今天已到期任务在两视图重叠，不相加。未来 7 天从明天起算，待办另提供全部未来及已完成视图。
- 客户页全宽行动表格：名称、联系人、最近跟进、下一步计划；我的客户/公海页内切换。公海不返回私有联系人或备注。搜索本人可见客户名称/编码/联系人，公海搜索只覆盖名称/编码。
- 新建入口明确“新增潜客”；已有精斗云客户先搜索、公海认养，不重复创建。保留共同认养信息，不把“报价中/已成交/沉默”等混合概念做互斥分类。
- 商机保留在客户详情，原有联系人、标签、跟进、任务、交易及操作历史仍可使用。新增轻量跟进弹窗，可自动带入客户和当前待办。
- 从待办记录跟进，可同时完成本次任务、创建下一步；操作一次事务提交。重复完成同一任务返回 409，不重复创建跟进。共同认养客户的本次新跟进生成的下一步归当前销售，避免自动分给其他负责人。
- 我的业绩使用现有 BI 后端指标，进度条由真实完成率驱动；已核实交易趋势由 ECharts 绘制。缺数据明确说明，不引入图片里的示例金额。原始交易与跟进不混表，没有无后端支持的导出/通知按钮。
- 对桌面和手机分别适配；长表仅局部横向滚动。跟进表单使用原生 dialog，支持键盘焦点、Escape、取消及保存时禁用。

## 数据与权限

新增 `/api/sales/customers`、`tasks`、`recent` 与 `customers/{id}/followup`。该组接口为销售本人的展示/操作入口，拒绝其他角色；原有老板/经理/财务/管理员接口不改变。数据仍经过客户所有权或有效认养、任务执行人校验。与其他销售相关的任务不得被完成；客户或任务不可见统一返回 404。

新增展示 DTO，不变更数据库结构，不需要 migration。金额与核心指标仍由既有 Decimal/NUMERIC 后端计算。前端仅格式化数字、裁剪进度条至 0–100% 和向图表传输数值，不计算业绩口径。目标区汇总本人适用来源，交易图按选定来源展示，两者范围明确标注。

## 验证

- 新增后端测试：五角色准入、客户/联系人搜索范围、公海字段最小化、时间边界/分页计数、一次提交及重复请求、越权/无效联系人不保存、共同认养的下一步归属。
- 浏览器验收：四页导航、客户搜索和详情、跟进完成待办并创建下一步、前进后退、手机溢出、老板导航回归。使用隔离测试 schema；不在正式客户上创建演练数据。
- 最终执行结果在任务完成时补录。Docker 及人工业务验收仍独立，不因本机检查通过而自动标为完成。
