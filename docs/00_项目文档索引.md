# 松茂经营管理平台 V1 项目文档索引

**版本：** v0.1  
**日期：** 2026-09-08  
**用途：** Codex 开发前的统一入口。开发人员/Agent 必须按顺序阅读文档，不得只看 PRD 就直接编码。

## 1. 项目一句话

在**不替代、不改动精斗云**的前提下，建设一套公司内部 Web 系统：

- 精斗云继续承担进销存和交易事实；
- 本系统提供轻量 CRM 与销售工作台；
- 精斗云导出数据、CRM 数据、财务报表进入统一数据中台；
- 老板通过 BI 驾驶舱查看销售、客户、商品、业务员、财务、风险等；
- 第一版以 Excel/CSV 手动同步为主，后续预留精斗云 API；
- AI 为可选增强层，核心计算和分析不得依赖 AI。

## 3. V1 明确不做

- 不替代精斗云的销售开单、采购、库存、出入库、财务记账；
- 不把 CRM 做成复杂的 Salesforce/纷享销客级系统；
- 不做独立原生 App；Web 必须适配手机；
- 不强制接精斗云 API；先支持手动导入；
- 不让 AI 直接承担销售额、毛利、同比环比等核心计算；
- 不做员工鼠标/在线时长监控；只记录登录和有效业务动作；
- 不做销售人员单一“综合评分”作为绩效结论。

## 4. 交付原则

开发以小里程碑循环：

`计划 -> 实现 -> 自动测试 -> 自检 -> 修复 -> 回归测试 -> 演示/验收 -> 冻结版本 -> 下一里程碑`

任何模块未达到本里程碑退出条件，不得为了“看起来进度快”提前堆下一模块。软件最擅长的就是把早期偷懒变成后期宗教仪式，本项目尽量不参加。
