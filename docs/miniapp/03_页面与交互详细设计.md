# 好客齐鲁微信小程序 CRM
## 页面与交互详细设计

这份文档解决“页面到底怎么搭”。

UI 细节尺寸见 `04_UI设计系统与Zcode强约束.md`。

---

# 0. 全局导航

一级 Tab：

```text
工作台 | 客户 | 附近 | 我的
```

业务路径：

```text
工作台 → 今日待办 → 客户详情
工作台 → 搜索客户 → 客户列表 / 客户详情
工作台 → 语音记录 → 选择客户 → 记录跟进
工作台 → 附近客户 → 附近
客户 → 客户详情 → 记录跟进
附近 → 客户详情 → 记录跟进
我的 → 待办 / 跟进记录 → 客户详情
```

# 1. 工作台

参考：`ui/01_工作台.png`

## 页面顺序

### A. Header

- 产品名轻量展示；
- “上午好，张经理”类似问候；
- 当天日期；
- 不要把 Logo / 平台名做成巨大 Banner。

### B. 今日待办

默认 4 条，最多 5 条。

TaskRow：

```text
[复选/状态] 客户名                   今天 11:00
            跟进中秋礼盒采购需求       >
```

点击整行：打开客户详情，并在详情中突出待办。

点击复选：不要直接瞬间完成。弹出简洁确认或结果填写，沿用现有 Task 完成规则。

### C. 快速操作

三个等宽按钮：

- 语音记录（主按钮，深蓝）；
- 搜索客户；
- 附近客户。

### D. 最近查看客户

本地最多存 10 个 customer_id，首页展示 3 个。

每条：

- 客户名；
- 标签；
- 最近查看时间；
- 最近业务摘要。

### E. 今日行程建议

展示 1~3 条：

- 预计拜访时间（若来自任务）；
- 客户名；
- 地址；
- 距离；
- “去这里”。

没有有效定位时不要报错，改成：

> 开启定位后可查看附近客户和行程建议。

# 2. 客户列表

参考：`ui/02_客户列表.png`

## Header

标题“客户”。

## 搜索区

输入框占一行，placeholder：

`搜索客户 / 联系人 / 电话`

输入 300ms 防抖。

## Filter Chips

横向可滚动：

- 全部；
- A类；
- 待跟进；
- 30天未联系；
- 有商机。

单选主筛选即可，不要首版做复杂组合查询面板。

## 重点客户提醒

展示三个数字即可：

- 今日待跟进；
- 30 天未联系；
- 有商机。

它是导航提示，不是 BI。

## CustomerRow

字段：

```text
公司名            [A级客户]
礼品批发  节日礼盒  济南
张经理  138****6789
上次联系：04-16 | 跟进状态：沟通中 | 下次：今天11:00
```

手机号在列表脱敏，详情按权限显示完整号码。

## 加载

使用 cursor / offset 分页，每次 20 条。

不要一次把所有客户拉到手机。

## 无数据

没有“+新增客户”。

# 3. 客户详情

参考：`ui/03_客户详情_时间线.png`

## A. 客户 Header

内容：

- 公司图标 / 首字母头像；
- 客户名；
- 客户等级；
- 3 个以内标签；
- 主联系人；
- 角色；
- 电话。

## B. 三个快捷按钮

### 拨打电话

使用系统拨号能力。

### 导航前往

只有客户有坐标时直接调地图。

若无坐标但有地址：提示“地址尚未完成地图定位”，可复制地址。

### 全部联系人

打开联系人 Bottom Sheet 或二级页。

## C. 拜访前速览

四列：

1. 上次联系
2. 上次承诺
3. 当前商机
4. 近期订单

手机宽度不足时允许 2×2，但视觉参考优先一行四个紧凑项。

“上次承诺”优先从最近 Followup 的 `next_action` 取。

“当前商机”优先：

- status = active；
- 按预计成交日期 / 更新时间选择最相关一个。

“近期订单”来自现有订单事实，不用自己计算业务金额。

## D. 客户动态筛选

- 全部；
- 拜访；
- 沟通；
- 订单；
- 资料。

只改变当前时间线过滤，不刷新整个页面头部。

## E. Timeline Item

统一 DTO：

```ts
type TimelineItem = {
  id: string
  type: 'followup' | 'order' | 'opportunity' | 'material'
  occurredAt: string
  title: string
  actorName?: string
  contactName?: string
  summary?: string
  interactionMethod?: string
  ai?: {
    communicationSummary?: string
    customerNeeds?: string[]
    nextActions?: string[]
  }
  media?: MediaItem[]
  nextAction?: string
  nextFollowupAt?: string
  amount?: number
}
```

### 跟进卡

重点展示：

- 跟进方式；
- 内容；
- AI 摘要；
- 图片 / 音频；
- 下一步。

### 订单卡

只展示：

- 订单主题 / 日期；
- 金额；
- 少量商品摘要；
- 状态。

不要在时间线里塞完整订单明细。

## F. 记录跟进 FAB

固定右下。

避免遮挡最后一条时间线，页面底部增加安全区域。

# 4. 记录跟进

参考：`ui/04_记录跟进.png`

## A. 客户上下文

如果从客户详情进入，客户固定。

如果从工作台“语音记录”进入：

第一步弹出“选择已有客户”搜索框，选择后进入本页。

禁止出现“找不到？新增客户”。

## B. 联系人

默认 Primary Contact。

可切换现有联系人。

## C. 沟通方式

Button Chip：

- 上门拜访；
- 电话；
- 微信；
- 其他。

映射现有 interaction_method。

## D. 发生时间

默认当前时间，可调整。

## E. 三个输入按钮

### 语音记录

主按钮。

状态机：

```text
idle
recording
recorded_local
uploading
uploaded
transcribing
transcribed
error
```

UI 必须显示当前状态。

### 拍照上传

允许：

- 相机；
- 相册。

V1 推荐最多 9 张 / 次，客户端压缩后上传。

### 手动输入

打开文本区并定位焦点。

## F. 转写文字

转写完成以后：

- 用户可以编辑；
- 原始 ASR 文本后台保留；
- UI 展示编辑后的工作文本。

## G. AI 智能整理

卡片四块：

- 沟通摘要；
- 客户需求；
- 下一步行动；
- 下次联系日期。

每一块都允许用户修改。

AI 不得自动修改：

- 商机金额；
- 订单金额；
- 客户等级；
- 财务事实。

如 AI 从谈话里识别到“预算 20 万”，只能作为摘要文字或商机建议，不直接修改 Opportunity.estimated_amount。

## H. 附件

横向缩略图：

- 图片；
- 音频波形卡。

支持删除未保存媒体。

已生成 media_token 的删除请求要让后端标记 / 清理临时文件。

## I. 保存按钮

### 保存并生成待办

如果 AI 生成了 nextAction，但用户没有确认日期，不允许自动猜一个日期静默保存。

用户确认 next_action + next_followup_at 后调用 Mobile Followup Create，底层复用 `save_followup()`。

### 仅保存记录

允许没有下一步。

# 5. 附近客户

参考：`ui/05_附近客户.png`

## A. 第一次进入

先显示权限说明：

> 位置仅用于查询你附近的已有客户和打开导航，不用于后台持续追踪。

用户同意后再请求定位权限。

## B. 地图区

约占首屏 45%~55%。

展示：

- 当前点；
- 客户 Marker；
- 地名底图；
- 回到当前位置。

默认半径：3km。

选择：

- 1km
- 3km
- 5km
- 10km

## C. Marker

只展示权限范围内客户。

点击：

- 地图底部 Sheet 滚动到对应客户；
- 或展示紧凑客户卡。

## D. 列表

按距离。

Customer Nearby Row：

```text
山东华礼商贸有限公司       [查看] [导航]
A类客户 礼品批发 济南
0.8公里 | 42天未联系
```

## E. 导航

调用微信 / 系统地图 `openLocation`。

不要自己在 V1 开发地图路线导航算法。

# 6. 我的

参考：`ui/06_我的.png`

## A. 用户信息

- 姓名；
- 销售员；
- 头像如系统无头像可用首字母默认头像。

## B. 轻量工作数量

只展示过程：

- 待办；
- 跟进记录；
- 本周拜访（可选）。

不要展示金额。

## C. 我的待办

最多 3 条 + 查看全部。

## D. 我的跟进记录

最多 3 条 + 查看更多。

## E. 常用功能

- 语音记录；
- 我的客户；
- 拜访路线；
- 拍照资料。

“拍照资料”进入时必须选择已有客户，再绑定到一条跟进或新建“其他”跟进。

## F. 设置与帮助

- 消息提醒；
- 同步状态；
- 使用说明；
- 退出登录。

---

# 7. 登录页

这是技术必需页，不改变六个业务页面范围。

V1：

- 用户名；
- 密码；
- 登录按钮；
- 产品名小字号；
- 无夸张 Banner。

不需要注册。

不需要忘记密码流程，继续由管理员处理账号。

---

# 8. 通用状态

所有页面必须有统一：

- Skeleton / Loading；
- Empty；
- Error；
- Retry；
- Offline；
- Unauthorized。

不得出现“接口报错 JSON 原文”。

---

# 9. 页面级缓存

建议：

- 客户列表筛选保留；
- 客户详情返回后滚动位置保留；
- 记录跟进未保存草稿本地缓存；
- 附近页面不缓存销售 GPS；
- 最近查看客户本地缓存 customer_id + viewed_at。

---

# 10. 刷新策略

工作台、客户详情：支持下拉刷新。

记录跟进：禁止下拉刷新，避免误操作清空内容。

附近：位置改变明显或用户点“刷新附近”时请求。
